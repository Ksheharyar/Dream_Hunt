
# 🌙 Dream Hunt

Dream Hunt is a simple browser-based adventure game developed using **HTML, CSS, and JavaScript**. Players explore the world, interact with the environment, and progress through the game using smooth controls and engaging gameplay mechanics.

# 🚀 Project Overview

Dream Hunt is a lightweight web game created to practice core web game development concepts using vanilla JavaScript. The project focuses on responsive gameplay, interactive mechanics, and browser compatibility without relying on external frameworks.

---

# ✨ Features

- 🌍 Browser-based gameplay
- 🎮 Smooth keyboard controls
- ⚡ Lightweight and fast loading
- 🖥️ No installation required
- 📱 Responsive design
- 🎯 Interactive gameplay mechanics
- 🚀 Built using pure JavaScript

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

# 🎯 Gameplay

- Explore the game world
- Navigate using keyboard controls
- Interact with game elements
- Complete objectives and enjoy the adventure
